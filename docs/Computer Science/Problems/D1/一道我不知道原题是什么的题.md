## Statement

定义函数f(x) 为 x 的各位数字之和，例如$f(13) = 4,f(233) = 8$。 给定正整数$n$和$s$，若$\sum_{i=l}^{r}{f(i)} \le s$，则区间$[l,r]$是勃勃生 机的。 问满足$0 \le l \le r \le n$的勃勃生机区间有多少。 $n \le 10^{18}, s \le 10^6$

## Step 1

Observations: 
1. If $[l, r]$ is good, then any one of its containing interval is good. Two pointers.
2. $r-l+1 \le C < 10^6$ ($C \le 10^5$)
