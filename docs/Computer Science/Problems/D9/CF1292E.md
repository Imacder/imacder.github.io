## Step 1

We can consider pushing down the value by breaking the strings up. However, we actually don't need all the positions of CHO, we only need 2 and we can infer the 3rd.

we need CC CO CH (or CC HC OC) to cover all Cs.
similarly we need HH CH OH (or HH HC HO) to cover all Hs.

we notice that we can eliminate one of them to a set of 5:

This allows us to get down to 1.25 for large n. But we don't know what the ends looks like. They can be:

We needs to check once for each side. This gives a total of $1.25 + \frac{1}{(n-1)^2} + \frac{1}{n^2}$. This is below 1.4 for $n \ge 5$.
