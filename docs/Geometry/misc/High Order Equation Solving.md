# High Order Equation Solving

Usually, finding an equation in this form indicates that this isn't the correct solution. However, when no other
method can be found, this is usually worth an attempt.

## Key 1

**KEEP THE EQUATION IN FACTORIZED FORM AS MUCH AS POSSIBLE**

This can help reduce the order of the equation can cancel out some terms (usually fake roots.)

## Key 2

**CHECK FOR SPECIAL ROOTS FIRST**

The fake roots introduced in the equation usually do have some geometric meaning. Some of them include:

1. 0: The size of the figure is 0.
2. Same length as some other segment: Reduces some other part of the figure.
3. Some solution in the opposite direction. (This usually can't be used for root testing.)
