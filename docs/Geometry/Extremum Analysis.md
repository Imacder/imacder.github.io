There are 2 main strategies:
1. Kinematics.
2. Algebraic Method.

## Kinematics

### Type 1

This is the easy type. We essentially find what locus it traces, then find the extremum point. The locus part is discussed in other articles.

### Type 2

We set the value to be maximized / minimized to be $k$, this is usually is enough to make to figure rigid (or at least we can check if a solution exists.) Then we gradually increase / decrease $k$ until it reaches a point where a solution exists by not beyond, this is the extremum.

### Sum of Segment Lengths

There are certain criteria that have to be met for the construction of this type of problem:
1. All the segments must be connected end to end. If not, translate them to be so.
2. The start $S$ and end $T$ of the chain of segments must be stationary.
3. All the locus of the intermediate points must intersect with segment $ST$ (for minimization.)

## Algebraic Method

This uses the same kind of elimination method as mentioned in [General Methodology](./General%20Methodology.md). But we have to do it in a smart way to avoid the algebraic mess.

For most problems we can just express the value in question as a function of a single variable (though the variable must be defined carefully), then find the function's extremum algebraically.

Though there are certain problems that require more variables for the value to be expressed. (Maybe there are more DoF, or you can express but its hard to do directly with geometry.)
